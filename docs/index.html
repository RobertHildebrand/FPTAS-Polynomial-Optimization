Small cells.

A curved objective. A lattice of feasible points. The surprising move is to organize the constraint slacks, then keep just one integer point per cell.

min f(x)   subject to   Ax ≤ b,   x ∈ ℤᵈ

For a bounded rational polyhedron, refined reflecting cells and Markov’s polynomial inequality give a range-relative approximation scheme. This guide lets you pull the geometry apart.

INSIDE THE SELECTED CELL

Relative width is the invariant.

With sᵢ(x) = bᵢ + ½ − aᵢᵀx, each cell has Lᵢ ≤ sᵢ ≤ Uᵢ and Uᵢ − Lᵢ ≤ Lᵢ/ℓ. This compares the interval width to its lower endpoint.

What this demo computes—and what it does not

This small example enumerates all feasible lattice points and assigns each to one incident full-dimensional chamber. A common infinitesimal direction resolves boundary ties. It keeps the first point in lexicographic order in each assigned group, independently of f. The count is of these groups, not all geometric chambers. Closed cells may overlap on their boundaries.

The picture uses the actual thresholds 2ᵏ(1 + j/ℓ), −2 ≤ k < 5, 0 ≤ j < ℓ, plus 32. Here Φ = 5 suffices by direct inspection. Q is defined by ¼ ≤ sᵢ ≤ 32, and contains every feasible integer point. The theorem uses a general encoding-based choice of Φ.

The paper’s algorithm enumerates chambers and calls integer linear feasibility, instead of enumerating lattice points. The demo uses floating-point geometry for illustration; the repository’s Python experiments use exact rational arithmetic. An observed error is not a proof of the guarantee.

02 / THE PROOF, IN FOUR MOVES

Geometry supplies samples.
Markov controls what happens between.

1

Move the boundary, keep the integers.

Replace b by b + ½. Because A and b are integral, the shifted polyhedron has exactly the same integer points. All feasible lattice points now have positive slack.

P̃ ∩ ℤᵈ = P ∩ ℤᵈ
Lean: integer shift and line restriction ↗
2

Nearby slack ratios give long segments.

If x and y share a refined cell, extrapolation about either point stays in P̃ for |t| ≤ ℓ. If x and y are integral, the integer samples return to P.

x + k(y − x) ∈ P   (k ∈ ℤ, |k| ≤ ℓ)
Lean: cells, coverage and progressions ↗
3

Cancel the odd part.

Restrict f to the line: p(t) = f(x + t(y − x)). At a global integer minimizer x, p(−1) ≥ p(0). Symmetrization makes the even part a polynomial in t², and a second Markov estimate gains ℓ² in the denominator.

e(t) = [p(t) + p(−t)]/2 = h(t²)
Lean: sampled bound, assuming Markov ↗
4

One representative is enough.

The representative in the minimizer’s cell is already good enough. Evaluate all representatives and keep the best. No continuous stationarity or local linear optimization is needed.

f(y) − fmin ≤ (D²/ℓ²)(fmax − fmin)

Choose ℓ = max{D², ⌈D/√ε⌉}. This is a range-relative guarantee, not a multiplicative guarantee for arbitrary signed minimization.

THE SYMMETRIZATION LENS

Watch the odd part disappear.

A concrete cubic p(t) = (t/ℓ)² + c(t/ℓ)³ has its sampled minimum at zero for |c| ≤ 0.8. Its even part is exactly (t/ℓ)². Dots mark integer samples.

p(t) Even part e(t)
The analytic step, with its hypotheses

Suppose deg p ≤ D, ℓ ≥ D², all integer samples on [−ℓ,ℓ] lie in [a,b], and p(−1) ≥ p(0). Center p by (a+b)/2. Markov and a nearest-integer argument bound the continuous supremum W by b−a. Write the centered even part as h(t²), with deg h ≤ ⌊D/2⌋. Applying Markov on [0,ℓ²] gives

p(1) − p(0) ≤ 4⌊D/2⌋²(b−a)/ℓ² ≤ D²(b−a)/ℓ².

The discrete samples are essential: their bounds come from the integer objective range. A continuous range or a coefficient-based Lipschitz constant would not supply the same guarantee. Classical Markov inequalities are explicit hypotheses in the Lean development.
